# Aprendendo SQL

Repositório para registrar meus estudos de SQL. Os arquivos vão sendo adicionados conforme eu avanço nos estudos, cobrindo desde os comandos básicos até tópicos mais avançados.

## Conteúdo

Cada arquivo `.sql` corresponde a um tópico ou exercício estudado (seleção de colunas, filtros, joins, agregações, etc.). Este repositório é atualizado continuamente à medida que novos conceitos são aprendidos.

## Como usar

Os arquivos contêm consultas e exercícios de estudo. Para executá-los, use um SGBD de sua preferência (MySQL, PostgreSQL, SQLite, etc.), rodando o conteúdo de cada script no cliente ou terminal correspondente.

## Contexto

Repositório em construção, criado para acompanhar minha jornada de aprendizado em SQL.
